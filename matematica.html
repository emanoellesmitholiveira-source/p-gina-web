Função do 1º e 2º Grau

Função do 1º Grau (Afim): Representada por f(x) = ax + b. Seu gráfico é uma reta. Se 'a' for positivo, a reta é crescente; se for negativo, é decrescente.

Função do 2º Grau (Quadrática): Representada por f(x) = ax² + bx + c. Seu gráfico é uma parábola. O valor de Δ (Delta) define as raízes e a concavidade depende do sinal de 'a'.

Progressão Aritmética (P.A.) e Geométrica (P.G.)

P.A. (Progressão Aritmética): Sequência onde a diferença entre termos vizinhos é constante (razão r). Os termos somam um valor fixo. Fórmula do termo geral: an = a1 + (n - 1) * r.

P.G. (Progressão Geométrica): Sequência onde cada termo é multiplicado por uma razão fixa (q). Fórmula do termo geral: an = a1 * q^(n - 1).

Geometria Plana: Áreas das Principais Figuras

Principais fórmulas de área para memorizar:

  • Quadrado: Lado x Lado (L²)
  • Retângulo: Base x Altura (b x h)
  • Triângulo: (Base x Altura) / 2
  • Círculo: π x Raio² (π.r²)
